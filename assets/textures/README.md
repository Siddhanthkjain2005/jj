# Material provenance

`asphalt-source.png` was generated for this project using the built-in image-generation tool on9November2026. It is an AI-generated material asset, not a photograph of a measured physical road. `asphalt-albedo.jpg` is a JPEG transcode for runtime download/bundle size. Normal perturbation is derived from neighbouring albedo texels in the shader; it is an artistic approximation, not a scanned height map.

Prompt used:

> Use case: photorealistic-natural. Asset type: seamless3D game road albedo texture, a single square material tile filling the entire image edge to edge. Primary request: photorealistic very fine-grain dark neutral-grey motorsport asphalt, expertly laid dense bituminous aggregate with subtle varied stone sizes, tiny restrained worn patches and natural micro pores; premium racing circuit surface, not a badly damaged public road. Orthographic straight-down macro photograph of an approximately2by2metre patch. Completely flat even diffuse illumination, no directional shadows, no perspective, no vignette, no baked reflections, no water, no painted lane lines, no objects, no text, no logos, no border. Texture should tile seamlessly on all four edges and have uniform overall tonality, no large recognizable repeating mark. Neutral desaturated charcoal, not blue, fairly dark but micro-detail legible. Output a square high-resolution material map, ideally2048by2048.

The actual generated source was1254×1254; no2048px claim is made. Font files in `../fonts/` come from Google Fonts and retain their bundled SIL Open Font Licenses. The game has no third-party advertising/analytics or online community backend; the packaged fonts/material are embedded into the standalone HTML.
